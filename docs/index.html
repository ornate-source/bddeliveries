BDDeliveries

A unified delivery gateway package for Node.js. One API for Pathao, Steadfast, and Paperfly.

Node 18+ TypeScript Zero Config 3 Gateways MIT License

Designed for developers who need to integrate multiple courier providers without writing gateway-specific code. Call createOrder(), trackOrder(), or cancelOrder() — and let BDDeliveries route to the right adapter internally.

Installation

Install the core package:

npm install bddeliveries

Configuration

BDDeliveries supports a three-tier credential system. Use whichever method fits your app — or combine them. Highest priority wins.

1

Per-Call Overrides Highest Priority

Pass credentials directly in any function call. Useful for multi-tenant apps where different merchants have different keys.

2

Global configure() Recommended

Call once at app startup to set credentials for all gateways you use.

3

Environment Variables Zero Config

Set env vars and the package reads them automatically — no code needed.

Global Configure Example

import { configure } from 'bddeliveries';

configure({
  pathao: {
    clientId: process.env.PATHAO_CLIENT_ID,
    clientSecret: process.env.PATHAO_CLIENT_SECRET,
    username: process.env.PATHAO_USERNAME,
    password: process.env.PATHAO_PASSWORD,
  },
  steadfast: {
    apiKey: process.env.STEADFAST_API_KEY,
    secretKey: process.env.STEADFAST_SECRET_KEY,
  },
});

Per-Call Override Example

import { createOrder } from 'bddeliveries';

// This apiKey overrides whatever was set in configure()
await createOrder({
  gateway: 'steadfast',
  apiKey: 'API_KEY_OVERRIDE',
  secretKey: 'SECRET_KEY_OVERRIDE',
  recipientName: 'John Doe',
  address: 'Dhaka',
});

Quick Start

Get up and running in three steps: configure, create, and track.

import { configure, createOrder, trackOrder } from 'bddeliveries';

// 1. Configure credentials once
configure({
  pathao: { clientId: '...', clientSecret: '...', username: '...', password: '...' },
});

// 2. Create Order — same function, any gateway
const order = await createOrder({
  gateway: 'pathao',
  recipientName: 'Jane Doe',
  address: 'Mirpur, Dhaka',
  amount: 1500,
});

console.log(order.trackingId); // "PATHAO-..."
console.log(order.status);     // "created"

// 3. Track Order
const tracking = await trackOrder({
  gateway: 'pathao',
  trackingId: order.trackingId,
});

console.log(tracking.status);  // "in_transit"

Create Order

Create a delivery order through any gateway. Pass gateway plus the relevant options.

const result = await createOrder({
  gateway: 'pathao',
  recipientName: 'John Doe',
  address: 'Gulshan, Dhaka',
  amount: 2000,
});

Track Order

Track a delivery. Pass the trackingId from the original order.

import { trackOrder } from 'bddeliveries';

const status = await trackOrder({
  gateway: 'pathao',
  trackingId: 'PATHAO-12345',
});

console.log(status);

Cancel Order

Cancel an existing order. Some gateways may only allow cancellation before dispatch.

import { cancelOrder } from 'bddeliveries';

const cancellation = await cancelOrder({
  gateway: 'steadfast',
  trackingId: 'STEADFAST-98765',
});

console.log(cancellation.status); // "cancelled"

Error Handling

BDDeliveries provides a structured error hierarchy for precise error handling.

import {
  createOrder,
  DeliveryError,
  GatewayNotFoundError,
  ConfigurationError,
} from 'bddeliveries';

try {
  await createOrder({ gateway: 'pathao', recipientName: 'Jane' });
} catch (error) {
  if (error instanceof ConfigurationError) {
    // Missing API keys
    console.log('Missing:', error.missingKeys);
  } else if (error instanceof GatewayNotFoundError) {
    // Unknown gateway name
    console.log('Unsupported gateway');
  } else if (error instanceof DeliveryError) {
    // Gateway-specific failure
    console.log(error.gateway);
    console.log(error.code);
    console.log(error.originalError);
  }
}

TypeScript Support

Full type definitions are included.

import {
  createOrder,
  configure,
  type CreateOrderOptions,
} from 'bddeliveries';

const options: CreateOrderOptions = {
  gateway: 'pathao',
  recipientName: 'Jane',
};

const result = await createOrder(options);

API Reference

Functions

Function Description Returns
configure(configs) Set global credentials for one or more gateways. void
clearConfig() Clear all stored global configuration. void
createOrder(options) Create an order through any gateway. Promise<any>
trackOrder(options) Track an existing order. Promise<any>
cancelOrder(options) Cancel an existing order. Promise<any>
getSupportedGateways() Returns array of supported gateway names. string[]
